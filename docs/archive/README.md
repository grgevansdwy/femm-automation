# Archive

Everything here is **superseded, historical, or generated** — kept for the record, not
maintained. If you're looking for current facts about this project, you almost certainly
want `docs/Engine.md`, `docs/GUI.md`, or `docs/Agent.md` instead — see `docs/README.md`.

Nothing in this folder is guaranteed to describe the code as it exists today. Several
files describe code paths, directories, or even whole packages (`noelle/`, `genki/`,
`legacy/webapp/`) that have since been deleted.

## `backend/agent/docs/` is a separate folder, not part of this archive

Working docs and dated run logs specific to the agent package live at
`backend/agent/docs/` (`gui_agent_plan.md`, `concurrency_plan.md`,
`interview_test_cases.md`, `hard_requirement_run.md`, `latest_run.md`,
`objective_generalization_plan.md`, `free_variables.md`) — some are referenced by name in
code comments/docstrings, so they weren't moved here. Treat them the same way: useful
history and test scripts, not guaranteed current.
